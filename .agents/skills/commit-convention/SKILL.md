# Commit convention

The entire commit message MUST be exactly one lowercase letter, with no body:

- `¶` — content: ideas, arguments, information; additions, corrections, deletions.
- `≈` — style: wording without changing meaning, spelling, typography, CSS, layout.
- `∷` — project: file structure, configuration, tooling, build, CI, dependencies, deployment, licensing.

Classify by what changes, not whether it is an addition or a fix.
Split independent changes into separate commits; otherwise use the primary purpose.
When asked for a commit message, return only the letter. No exceptions.
