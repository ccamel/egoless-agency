# Commit convention

The entire commit message MUST be exactly one symbol, with no body:

- `¶` — what we think: ideas, arguments, information.
- `≈` — how we express it: wording, typography, CSS, layout.
- `∷` — how the project works: structure, configuration, tooling, build, CI, dependencies, deployment, licensing.

Split independent changes into separate commits; otherwise use the primary purpose.
When asked for a commit message, return only the symbol.
